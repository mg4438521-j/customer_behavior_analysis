# Data Analytics Project

Overview

This project demonstrates an end-to-end data analytics workflow using Python, SQL, PostgreSQL, and Power BI. The objective was to clean, analyze, and visualize data to generate actionable insights and support data-driven decision-making.

## Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* PostgreSQL
* SQL
* Power BI

 Project Workflow

1. Loaded and explored the dataset using Python.
2. Performed data cleaning and preprocessing.
3. Conducted Exploratory Data Analysis (EDA).
4. Executed SQL queries in PostgreSQL to extract insights.
5. Built an interactive Power BI dashboard.
6. Summarized findings through reports and presentations.

Key Skills Demonstrated

* Data Cleaning
* Exploratory Data Analysis (EDA)
* SQL Querying
* Database Management
* Data Visualization
* Dashboard Development
* Business Insights Generation

Outcome

Successfully transformed raw data into meaningful insights through data analysis, SQL querying, and interactive dashboard creation.
